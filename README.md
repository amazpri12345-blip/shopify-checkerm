# Flezen Telegram Video Bot

## Railway setup

1. Create a Telegram bot with BotFather and copy the bot token.
2. Upload this project to Railway.
3. Add an environment variable:

BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN

4. Deploy.

## Important

This version downloads direct video-file URLs such as .mp4/.webm.
A normal Flezen page URL requires a documented Flezen API/endpoint to
resolve the page into a video. No undocumented/private endpoint is included.
